# About ISCI Security Solutions

ISCI Security Solutions is an independent security engineering and software development initiative focused on developing practical security technologies, open-source tooling and engineering solutions.

Our work encompasses security research and development, software engineering, infrastructure security and security automation. We explore technical challenges, develop purpose-built tools and investigate approaches that improve security operations, system resilience and technical capabilities.

Through open-source development, technical research and practical experimentation, ISCI aims to contribute useful technologies and knowledge to the broader information security and software engineering communities.

Areas of focus

- Security Engineering & Software Development
- Research & Development
- Open-Source Security Tooling
- Security Automation & Orchestration
- Infrastructure & Systems Security
